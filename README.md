# 心有靈排

排出你的真心，猜中朋友的腦袋。2–10 人的排名派對遊戲（繁體中文）。

## 玩法

- **🎯 猜猜主角**：每回合一位主角，把 5 個詞照真心排成 S（最愛）到 D。其他人同時猜主角怎麼排。揭曉從 D 翻到 S：位置全對 2 分、差一格 1 分，全部猜中再 +5。主角拿大家的平均分。
- **🔮 全員神同步**：沒有主角，大家一起排同一題，目標排得一模一樣，拚連續同步回合數。3 人以上會出「排排看你的朋友」題，詞語就是玩家名字。
- 最後頒獎：全場最會讀心、名偵探、一秒看穿、謎一樣的人、讀心術大師、靈魂伴侶、唱反調王…

## 兩種開局

- **開房間**：每人用自己的手機開同一個頁面、輸入 4 碼房號加入。線上同步使用 claude.ai Artifact 的 `room` 功能，所以只在 claude.ai 上開啟、且玩家已登入並取得頁面存取權時可用。
- **一支手機輪流玩**：不需要連線，任何地方開 `index.html` 都能玩。輪到誰就把手機交給誰，揭曉時大家圍過來看。

## 題庫

- 內建 120+ 題（美食、台灣日常、生活、娛樂、戀愛、學校職場、腦洞），每題 7–10 個詞，每回合隨機抽 5 個，同一題每次玩都不一樣。
- 25 題「排排看你的朋友」題（神同步模式）。
- **自訂題目**：首頁「我的自訂題目」可以加入自己的梗（存在瀏覽器）。線上玩時，房裡每個人的自訂題目都會混進題庫，並標出是誰出的題。

## 開發

```
src/game.html    遊戲本體（HTML/CSS/JS，無外部函式庫）
src/prompts.txt  題庫：分類|題目|詞1,詞2,...
build.py         把題庫塞進遊戲，產生 index.html（獨立網頁）與 dist/artifact.html（claude.ai Artifact 用）
```

改完執行 `python3 build.py`。音效全部用 WebAudio 即時合成，沒有音檔。
