# 心有靈排

排出你的真心，猜中朋友的腦袋。2–10 人的排名派對遊戲（繁體中文）。

## 玩法

- **🎯 猜猜主角**：每回合一位主角，把 5 個詞照真心排成 S（最愛）到 D。其他人同時猜主角怎麼排。揭曉從 D 翻到 S：位置全對 2 分、差一格 1 分，全部猜中再 +5。主角拿大家的平均分。
- **🔮 全員神同步**：沒有主角，大家一起排同一題，目標排得一模一樣，拚連續同步回合數。3 人以上會出「排排看你的朋友」題，詞語就是玩家名字。
- **⚖️ 二選一**：每題兩個選項（情境、美食、價值觀、私密問題、戀愛、金錢、職場、友情、腦洞、政治），大家偷偷選一邊，再猜「多數人會選哪邊」（可略過，猜中 +2，平手不計分），可以留一句理由。這個模式沒有特殊回合，題目不夠勁爆可以換題。揭曉後會點名人出來辯護或回嘴。揭曉時列出誰站哪邊、貼出理由，方便吵架。頒獎：最會讀空氣、少數派代表、人民的聲音、孤鳥、價值觀雙胞胎、天生冤家。
- 🔥 加倍押注：猜的人可以押一列最有把握的，押中 +3、押錯 −1。
- ⏱️ 倒數計時（不限時／90／60／30 秒），時間到自動送出。
- 最後一回合是決勝回合，分數 ×2；每回合結算會點出「最大驚嚇」。
- 最後頒獎：全場最會讀心、名偵探、一秒看穿、謎一樣的人、讀心術大師、賭神、靈魂伴侶、唱反調王…

## 讓每回合都有戲

- **辯解**：主角排完可以留一句話，揭曉前貼給大家看。
- **最懂他的人**：揭曉前大家先投票，投中本回合最高分的人 +2。
- **每回合的小事件**：反轉回合（排出最不像主角的排法）、雙主角（4 人以上，猜兩人合起來的排名）、豪賭回合（押中 +6、押錯 −2）、閃電回合（25 秒）、決勝回合（最後一回合 ×2）。
- **成果卡**：頒獎後產生一張可以截圖分享的卡片，含名次、獎項、本日名場面與最經典的辯解。

## 兩種開局

- **開房間**：每人用自己的手機開同一個網址、輸入 4 碼房號（或點邀請連結）加入。
  - 部署在 Render 等主機時，由 `server.js` 的 WebSocket 轉送連線，任何人打開網址就能玩。
  - 在 claude.ai Artifact 裡開啟時，改用 Artifact 的 `room` 功能（玩家需登入並取得頁面存取權）。
- **一支手機輪流玩**：不需要連線，任何地方開 `index.html` 都能玩。輪到誰就把手機交給誰，揭曉時大家圍過來看。

## 題庫

- 內建 469 題，12 個分類（美食、台灣日常、生活、娛樂、戀愛、職場・校園、旅行、日常小確幸、迷因／網路文化、腦洞、爭議、童年），每題 8–10 個詞，每回合隨機抽 5 個，同一題每次玩都不一樣。
- 二選一題庫 577 題，10 個分類（美食、生活日常、戀愛、價值觀、私密問題、情境腦洞、職場・校園、金錢、友情・社交、政治・意識形態），可在設定裡開關分類；兩個選項的左右順序每次隨機。
- 40 題「排排看你的朋友」題（神同步模式）。
- **作者專屬測驗包**（200 題，上鎖）：設定裡點「🔒 作者專屬測驗包」輸入密碼解鎖，詞語固定是朋友圈的 9 個人名。解鎖後會記在這台裝置的瀏覽器。密碼只是前端軟鎖。
- **自訂題目**：首頁「我的自訂題目」可以加入自己的梗（存在瀏覽器）。線上玩時，房裡每個人的自訂題目都會混進題庫，並標出是誰出的題。題庫裡的「自訂題」可以像其他卡包一樣開關。

## 開發

```
src/game.html    遊戲本體（HTML/CSS/JS，無外部函式庫）
src/prompts.txt  題庫：分類|題目|詞1,詞2,...（詞語寫 * 代表用作者專屬測驗包的人名）
src/ab.txt       二選一題庫：分類|題目|選項A|選項B（分類 key 見 game.html 的 AB_CATS）
build.py         把題庫塞進遊戲，產生 index.html（獨立網頁）與 dist/artifact.html（claude.ai Artifact 用）
server.js        Node 伺服器：提供 index.html，並在 /ws 轉送房間狀態（斷線 45 秒內可重連回原位置）
```

改完執行 `python3 build.py`，本機測試 `npm install && npm start` 後開 http://localhost:3000。

## 部署到 Render

Web Service，Runtime 選 Node，Build Command `npm install`，Start Command `npm start`。免費方案閒置 15 分鐘會休眠，第一次打開要等約一分鐘。音效全部用 WebAudio 即時合成，沒有音檔。
